# CSSE6400 Week 5 Practical

This practical deploys the **TaskOverflow** application to AWS using **Terraform**.  
The deployment provisions a PostgreSQL database with **Amazon RDS** and runs the application in **Amazon ECS (Fargate)**.

Please see the [instructions](https://csse6400.uqcloud.net/practicals/week05.pdf) for more details.

## Overview

In this practical, the following AWS resources were created using Terraform:

- an RDS PostgreSQL database for persistent storage
- security groups for the database and application
- an ECS cluster
- an ECS task definition
- an ECS service running the TaskOverflow container

The application was successfully deployed and verified through the browser by opening the ECS task public IP on port `6400`.

## Files

- `main.tf` - Terraform configuration for AWS infrastructure
- `.terraform.lock.hcl` - provider lock file generated by Terraform

## Prerequisites

Before running this project, make sure you have:

- access to the AWS Academy Learner Lab
- Terraform installed
- a valid AWS CLI credentials file from Learner Lab

## How to Run

### 1. Start the Learner Lab
Launch the AWS Academy Learner Lab and copy the AWS CLI credentials from **AWS Details**.

Create a local `credentials` file in the project root and paste the credentials into it.

> Do not commit the `credentials` file to GitHub.

### 2. Initialise Terraform

```bash
terraform init
````

### 3. Preview the deployment

```bash
terraform plan
```

### 4. Deploy the infrastructure

```bash
terraform apply
```

Type `yes` when prompted.

## How to Access the Application

After deployment:

1. Open the AWS Console
2. Navigate to **ECS**
3. Open the `taskoverflow` cluster
4. Open the running service and task
5. Find the task public IP
6. Open the application in a browser:

```text
http://<public-ip>:6400
```

## Verification

The deployment was verified by:

* confirming the RDS instance status was **Available**
* confirming the ECS service had **1 running task**
* opening the TaskOverflow web interface in the browser
* creating a new todo item successfully

This confirmed that the application, ECS service, and RDS database were connected and working correctly.

## Clean Up

To remove all AWS resources after testing:

```bash
terraform destroy
```

Type `yes` when prompted.

## Notes

* The `credentials` file must remain local and must not be committed.
* Terraform state and local Terraform directories should also be ignored by Git.
* This practical focused on infrastructure deployment and cloud-based execution of the application.
